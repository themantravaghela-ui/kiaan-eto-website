# kiaan-eto-website
Official website for KIAAN ETO Centre Sterilization - Precision Sterilization Services in Ahmedabad, Gujarat.
KIAAN ETO - Spatial UI website

A responsive, static GitHub Pages website for KIAAN ETO Centre Sterilization. Built with plain HTML, CSS and JavaScript; there is no build step, API key or server dependency.

The typography pairs Space Grotesk display headings with readable Manrope body copy and compact DM Mono technical labels.

Deploy to your existing GitHub Pages repository

1. Download and unzip the supplied

kiaan-eto-spatial.zip (or copy this folder's contents).

2. Back up the existing repository before replacing files.

3. Copy index.html, style.css, script.js, and the complete


assets/ folder into the repository root. Keep the current Pages workflow/settings.

Commit and push the changed files to the branch/ folder already configured for GitHub Pages. The site will update at its existing URL after GitHub Pages finishes publishing
The page reuses the equipment and instrument photographs from the current public site. Do not remove or rename the files inside assets/ unless you also update their references in index.html.

Brand logo

assets/logo.png is your supplied KIAAN ETO mark, cropped and made transparent so it sits cleanly on the dark background. It is used in the header, footer and browser tab icon. To replace it later, keep the same path/name or update the image and favicon references in index.html.

Contact and backend note

GitHub Pages serves static files and does not run an application server or save enquiries to a database. The form validates its required fields, prepares an enquiry message and opens WhatsApp to +91 95585 37188; the visitor reviews and sends it in WhatsApp. The website itself does not store the submitted fields. Direct call links and info@kiaaneto.com are also included.
